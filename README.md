## Guía APE 4 - Programación Orientada a Objetos en Java

### Introducción

En este repositorio comparto la resolución de cinco ejercicios prácticos desarrollados en Java, como parte de la asignatura de **Introducción a la Programación Orientada a Objetos**. El propósito principal de este trabajo es llevar a la práctica los conceptos aprendidos en clases, tales como la creación de clases y objetos, la definición de atributos y métodos, así como el uso de estructuras condicionales y ciclos repetitivos.

Para hacerlo más dinámico, los ejercicios abordan escenarios de la vida cotidiana, tales como:

* El registro y cálculo de calificaciones estudiantiles.
* El control de stock y ventas para el inventario de una tienda.
* El registro de mascotas en una veterinaria.
* La simulación de depósitos mensuales en una cuenta de ahorro.
* La gestión de libros, socios y préstamos en una biblioteca.

A través de estas actividades, busco fortalecer mi lógica de programación, entender a fondo el paradigma orientado a objetos y ganar mayor soltura en el diseño y ejecución de programas utilizando Java.

---

### Tecnologías utilizadas

* **Lenguaje:** Java
* **Entorno de desarrollo:** Visual Studio Code
* **Control de versiones:** Git y GitHub

---

### Contenido del repositorio

**Gestión de notas:** Cálculo de promedios académicos y clasificación de estudiantes según su rendimiento.
**Control de inventario:** Administración de productos, registro de ventas y actualización de stock.
**Sistema de veterinaria:** Registro de mascotas y manejo práctico de referencias a objetos.
**Simulación de cuenta de ahorro:** Aplicación del ciclo `while` para calcular depósitos mensuales.
**Gestión de biblioteca:** Registro y control de libros, socios y préstamos vigentes.
